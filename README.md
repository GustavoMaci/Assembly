## 📚 Conteúdos Abordados

- **Estradas e Saídas**: Conceitos básicos de entrada e saída de dados
- **Operadores de Decisão**: Estruturas condicionais e operadores lógicos
- **Laços**: Estrutura de repetição 
- **Modularização**: Organização e estruturação de código em módulos
- **Acesso a Memória**: Manipulação e gerenciamento de memória
